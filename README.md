# bruederstein.de

Webseite des Vereins Auf Brüderstein e.V., Grillplatz der Gemeinde Hohenstein.

## Starten

```bash
bun install
bun run dev        # Entwicklung
bun run generate   # statische Seite nach .output/public
```

Benötigt Bun und Node.js 24. Deployment per `Dockerfile` (nginx).
